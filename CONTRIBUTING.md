# Zgłaszanie zmian (Contributing)

1. Sklonuj repozytorium.
2. Utwórz nową gałąź feature (`git checkout -b feature/nowa-funkcja`).
3. Wprowadź zmiany i upewnij się, że kod przechodzi wszystkie testy (włączając w to analizę linterem, np. ktlint, flake8).
4. Zacommituj zmiany (`git commit -am 'Dodano nową funkcję'`).
5. Wypchnij brancha (`git push origin feature/nowa-funkcja`).
6. Utwórz Pull Request.
